# 🎮 Hangman Game

A simple Hangman word-guessing game built using Python.

## 📌 About the Project

The player has to guess the hidden word by entering letters.

The game randomly selects a word from a predefined list and gives the player a limited number of attempts.

## 🚀 Features

- Random word selection
- Letter guessing
- Displays correctly guessed letters
- Shows remaining attempts
- Handles incorrect guesses
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Random module

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python hangman.py
